# skywheel

Website for Skywheel Astrology (`index.html`, `privacy.html`).

## AI app-development team

`agent_team/` contains a team of Claude agents that plans, builds, tests and markets an app: a Planner agent that hands work to Market Research, Coding, Debugging, Testing and Marketing specialists. See [agent_team/README.md](agent_team/README.md).

```bash
pip install -r agent_team/requirements.txt
python -m agent_team "A habit tracker web app for college students"
```
